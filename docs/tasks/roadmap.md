# Product Roadmap

## Phase 1: MVP Stabilization (Current)
- [x] Integrate Vercel Panchang API.
- [x] Build Premium UI/UX (Glassmorphism, Luxury Gold).
- [x] Fix Layout Traps & Overflows (Zero Overflow Rule).
- [x] Secure Authentication (Supabase Native SDK).
- [x] Password Recovery Deep-Linking.

## Phase 2: Core Feature Expansion (Next 4-6 Weeks)
- [ ] **E-Commerce Checkout:** Fully integrate Razorpay for buying spiritual products.
- [ ] **Puja Booking Flow:** Allow users to pick dates, input Gotra/Name, and pay for virtual or physical pujas.
- [ ] **Offline Mode:** Ensure Hive aggressively caches Shlokas and Aartis so they can be read/played without internet.
- [ ] **Security Audits:** Fix `flutter_jailbreak_detection` dependencies to secure the app against tampered devices.

## Phase 3: Engagement & Scaling (Months 2-4)
- [ ] **Live Audio Streaming:** Move from static mp3 files to a CDN-hosted streaming infrastructure for Bhajans.
- [ ] **Astrologer Consultations:** Add a chat/video module for users to book time with verified Pandits.
- [ ] **User Profiles:** Expanded profile settings, order history tracking, and downloadable invoices.
- [ ] **Push Notifications:** Automated daily reminders for Sunrise, Muhurtas, and Vrat (Fasting) rules.

## Phase 4: Platform Maturation
- [ ] Web/Desktop App deployment using Flutter Web.
- [ ] Multi-tenant architecture for Vendor Management (Allowing temples to sell prasad).
