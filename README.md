# Vedic Reeti - Mobile & Web Platform

This is my project named Vedic Reeti. It is a digital platform created to connect traditional spiritual practices and astrology with modern tech. The project includes a mobile app for users, an admin panel for managing things, and a backend server.

## Main Features

- **Spiritual Store:** Users can buy spiritual items. It supports multiple languages using database json features.
- **Panchang:** Shows daily calendar details like Tithi, Nakshatra, and auspicious times.
- **Offline Support:** The app works smoothly even when internet is slow or lost, using local caching.
- **Admin Dashboard:** Admins can check live orders and update things easily.
- **Payments:** Integrated payment gateway for safe checkout.

## Technologies Used

- **Mobile App:** Flutter & Dart
- **Web Admin:** Next.js & React
- **Backend & Database:** Supabase & PostgreSQL
- **Payments:** Razorpay
